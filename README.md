# SōmaSpell

**Words are the key to the soul’s remembrance.**

SōmaSpell is a consciousness-based language healing app designed to help users deconstruct distorted words, reframe them through the 7-Gate Mastery Process, and reclaim their soul’s energetic sovereignty.

## 🌟 Core Features

- 🔮 **Mystic Word Engine**: Enter any word and uncover its spellbinding origins.
- 🌀 **7-Gate Mastery Process**: Move through a healing journey of unbinding, redefinition, and sacred activation.
- 🎨 **Chakra-Aligned Insights**: Each gate works with your nervous system and energy centers.
- 🌹 **Neutral Word Recognition**: Words without fragmentation are honored in peace with sacred visuals.
- 💾 **Session Archive & Memory**: Save, resume, and reflect on your word journeys.

## 🛠️ Tech Stack

- React + TypeScript
- Chakra-based UI Design
- Light + Sound Frequency Integration
- Breathwork Modules

## 🚀 Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/your-username/somaspell.git
   cd somaspell
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the app:
   ```
   npm start
   ```
